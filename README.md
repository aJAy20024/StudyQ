# StudyQuest

A gamified student productivity website built with **HTML, CSS and JavaScript**.

## Features
- Responsive landing page
- Student dashboard
- Task/mission manager
- XP and level system
- Pomodoro focus timer
- Study streak
- Progress dashboard with charts
- Achievement badges
- Notes system
- Dark/light mode
- LocalStorage data persistence
- Mobile responsive layout
- GitHub Pages ready

## Folder structure
```text
StudyQuest/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
```

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a public GitHub repository.
2. Upload all files while keeping the same folder structure.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select **main** and **/(root)**.
6. Save and open the generated GitHub Pages link.
